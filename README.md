# 🌌 StellarInsight: Interactive Hertzsprung–Russell (HR) Diagram Generator

An interactive astrophysics visualization project that recreates the famous Hertzsprung–Russell (HR) Diagram using stellar data. The project processes and visualizes properties such as temperature, luminosity, radius, and absolute magnitude to classify stars into different evolutionary stages.

## ✨ Features
- Interactive HR Diagram using Plotly
- Static scientific visualization using Matplotlib
- Data cleaning and preprocessing
- Logarithmic scaling for accurate representation
- Inverted temperature axis following astrophysics standards
- Rich hover details including spectral class and star type

## 🛠️ Tech Stack
- Python
- pandas
- plotly
- matplotlib

## 📊 Dataset Attributes
- Temperature (K)
- Luminosity (L/Lo)
- Radius (R/Ro)
- Absolute Magnitude (Mv)
- Spectral Class
- Star Type
- Star Color

## 🚀 Run the Project

```bash
pip install pandas plotly matplotlib
python hr_interactive.py
python hr_graph.py
```
